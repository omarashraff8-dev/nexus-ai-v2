# NEXUS AI V2 — المنصة الجامعية الذكية للشكاوى والخدمات

إعادة بناء نظيفة ومستقلة لمشروع NEXUS AI بنفس الهوية البصرية العربية (RTL) ونفس الوظائف الكاملة، ببنية منظمة وفصل واضح بين السيرفر والواجهة والبيانات.
المشروع الأصلي `NEXUS-AI/` لم يُعدَّل نهائيًا — هذه نسخة مستقلة بالكامل.

> 🌐 نسخة ديمو ثابتة جاهزة في مجلد `docs/` (تعمل على GitHub Pages). النشر الفعلي في مستودع منفصل لم يتم بعد.

---

## التشغيل (3 خطوات)

المتطلبات الوحيدة: **Node.js 22.5 أو أحدث**. لا توجد أي مكتبات خارجية — المشروع يستخدم وحدات Node المدمجة فقط (`node:http` + `node:sqlite`).

```powershell
cd NEXUS-AI-V2
node server/index.js
```

ثم افتح: **http://localhost:3000**

لتغيير المنفذ:

```powershell
$env:PORT=3010; node server/index.js
```

قاعدة البيانات `data/nexus.db` مأخوذة من نسخة نضيفة (checkpoint) من بيانات المشروع الأصلي، والمرفقات في `data/uploads/`. عند أول تشغيل على قاعدة فارغة يتم إنشاء الجداول والبيانات التجريبية تلقائيًا.

### الشريط الجانبي (SidebarController)
منطق واحد مركزي في `web/js/sidebar.js` لكل اللوحات:
- زر هامبرجر واحد (click فقط — بدون تعارض pointer/touch/click).
- زر إغلاق X داخل الدرج على الموبايل.
- إغلاق تلقائي عند: اختيار أي عنصر تنقل، النقر خارج الدرج، زر Escape، أو تغيير المسار/الهاش.
- على الديسكتوب لا يتدخل الـ JS في التخطيط إطلاقًا.

## المميزات المنفذة

### الصلاحيات (RBAC) — في السيرفر
- الطالب يرى شكاواه فقط.
- الموظف يرى شكاوى قسمه أو المسندة إليه فقط.
- الإدارة ترى وتدير كل شيء.
- كل endpoint حسّاس محمي بالتحقق من الدور في السيرفر، وصفحات اللوحات محمية بحارس جلسة.

### لوحة الطالب
إحصائيات · تقديم شكوى (نوع + قسم + أولوية + مرفق صورة/PDF) · اقتراح ذكي · متابعة الحالة · محادثة مع الموظف · إشعارات · تقييم بالنجوم بعد الحل · مساعد RAG للوائح · خدمات أكاديمية (جدول، امتحانات، درجات وGPA، مصروفات، حضور، مستندات) · حضور QR · مفقودات وموجودات · إعلانات.

### لوحة الموظف
وارد الشكاوى مع بحث وفلاتر · تفاصيل ومرفقات · ردود · تغيير الحالة · طلب معلومات · تحويل قسم · ملاحظات داخلية · تولّي الشكوى · تأكيد الحل الداخلي · جلسات QR للحضور · مفقودات · إحصائيات الأداء.

### لوحة الإدارة
إدارة المستخدمين (إضافة/تعديل/تعطيل/حذف/إعادة كلمة مرور) · الأقسام وأنواع الشكاوى · كل الشكاوى مع إسناد · رسوم بيانية Canvas · أكثر المشكلات تكرارًا · توقع أسبوعي (انحدار خطي) · ملخص ذكي · «اسأل الإدارة» بالعربي · رضا الطلاب · إعلانات · تصدير CSV · طباعة التقرير.

### الذكاء الاصطناعي (بدون أي خدمة خارجية)
1. مساعد RAG يبحث داخل مستندات اللوائح المخزنة في القاعدة، مع استشهاد بالمصدر والصفحة، ويفهم العربي والعامية.
2. تصنيف تلقائي للشكاوى (نوع/قسم/أولوية/ثقة).
3. توقع حجم الشكاوى أسبوعيًا.
4. تلخيص عربي مبني على الأرقام الفعلية.
5. إجابات إدارية من بيانات القاعدة نفسها — بدون اختراع أرقام.

## ملاحظات أمان وتشغيل
- الجلسات: cookie `HttpOnly` + token عشوائي في جدول `sessions` (7 أيام).
- كلمات المرور: `scrypt` + salt لكل مستخدم.
- حد الطلبات 12MB، والمرفقات 8MB بأنواع محددة، وكل مرفق لا يُفتح إلا لصاحب الصلاحية.
- لا توجد مفاتيح أو أسرار في كود الواجهة؛ كل الذكاء الاصطناعي محلي في `server/ai.js`.
- عند الحاجة لربط Gemini/OpenAI لاحقًا: يتم النداء من السيرفر فقط (متغير بيئة)، وليس من المتصفح.
